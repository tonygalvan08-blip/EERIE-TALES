EERIE TALES — Episode 1: Eerie Springs Gas
==========================================

Night shift at a rural Appalachian gas station. A slow-burn first-person horror game.
You do NOT need Godot installed.

HOW TO INSTALL (Setup)
----------------------
1. Run EERIE_TALES_Setup.exe
2. If Windows SmartScreen appears ("Windows protected your PC"):
     click "More info" → then "Run anyway"
   (The installer is unsigned, which is normal for indie builds.)
3. Finish the wizard. A Desktop shortcut named "EERIE TALES" will be created.
4. Double-click the Desktop icon (or the Start Menu entry) to play.

PORTABLE VERSION
----------------
Unzip EERIE_TALES_Windows_Portable.zip anywhere and double-click EERIE_TALES.exe.
You can also right-click the .exe → Send to → Desktop (create shortcut).

CONTROLS
--------
  WASD          Move
  Mouse         Look
  E             Interact
  F             Flashlight
  Left click    Scan item (at the register)
  Tab           Show / hide chore list
  H             Toggle onboarding hints
  Esc           Pause / settings
  T             Debug time scale (testing)

UNINSTALL
---------
Use "Add or remove programs" in Windows Settings, or run
  Start Menu → EERIE TALES → Uninstall EERIE TALES
Portable: just delete the folder.

SYSTEM
------
  Windows 10/11 64-bit recommended.
  Built with Godot 4.7.2 (Forward+). Uses Direct3D 12 / Vulkan with OpenGL fallback.

Enjoy the night shift. Don't take candy from strangers.
