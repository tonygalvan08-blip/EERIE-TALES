# Credits — Eerie Springs Gas

## Code & Design
- Prototype built for Tony (2026) with Grok Bot

## Audio
All audio in `assets/audio/` is **procedurally generated** for this project (synthetic tones, noise, and simple envelopes). No third-party samples. CC0 / public domain equivalent as original generated works.

## Textures & Faces
- Store/product/environment textures: procedurally generated for this project
- Character face textures: AI-generated original portraits (Jake, Old Man, Day Clerk, customer sheet), downsampled for a remastered PS2-era look
- No trademarked brand names or logos — all product brands are fictional (CornBites, FizzRite, etc.)
